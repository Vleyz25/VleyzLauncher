# Политика конфиденциальности Vleyz Launcher

Дата последнего обновления: 24 ноября 2026 года.

Этот документ описывает, какие данные Vleyz Launcher читает, где они хранятся
и что с ними происходит. Коротко: всё остаётся на вашем компьютере, наружу
уходит только один анонимный счётчик установок, и его можно отключить.

## 1. Какие данные читает лаунчер

Лаунчер работает с файлами игры, которые уже лежат на вашем диске:

- `saves/<мир>/stats/*.json` — статистика Mojang: добытые блоки, крафты,
  убитые мобы, пройденные метры;
- `saves/<мир>/advancements/*.json` — выполненные достижения;
- `logs/` и `crash-reports/` — для разбора ошибок запуска;
- `mods/`, `mods-disabled/`, `config/` — для управления сборкой;
- файл `progress.json` в папке сборки — сводка, которую лаунчер считает сам.

Эти данные нужны для будущих достижений, квестов и магазина внутри лаунчера.
Сейчас прототип учёта действий только считает сводку и ничего не показывает
в интерфейсе.

## 2. Куда эти данные уходят

Никуда. Статистика, достижения, список модов, настройки и миры не передаются
на серверы проекта, не попадают в аналитику и не отдаются третьим лицам.
Лаунчер не читает чат, не снимает экран, не отслеживает нажатия клавиш и не
знает, с кем вы играете.

## 3. Единственная сетевая отправка: счётчик установок

При первом запуске после установки лаунчер отправляет один анонимный запрос
на счётчик проекта. В запросе нет ника, UUID аккаунта, IP-адреса в открытом
виде и содержимого файлов — только факт установки. Отметка о нём хранится
в файле `.install-ping`, поэтому повторно запрос не уходит.

Отключить можно в настройках или вручную: добавьте в `config.json` строку

```json
"telemetry": false
```

После этого лаунчер не отправляет ничего.

## 4. Что лаунчер не собирает

- ник, пароль и токены аккаунта Microsoft (вход идёт по коду устройства,
  пароль лаунчер не видит и не хранит);
- содержимое чата и голосовых чатов;
- историю браузера и другие программы на компьютере;
- геолокацию и контакты.

## 5. Где хранятся данные

Всё лежит локально в папке, которую вы выбрали при установке:

- `instances/<сборка>/` — миры, моды, конфиги, `progress.json`;
- `logs/` — журналы лаунчера;
- `config.json` — настройки (в профиле пользователя Windows).

Удаление `progress.json` стирает сводку учёта действий. Удаление папки сборки
стирает всё, что к ней относится.

## 6. Дети

Лаунчер не собирает персональные данные и не требует регистрации, поэтому
подходит для любого возраста. Родителям стоит знать: в интернете лаунчер
обращается только к официальным серверам Mojang, Modrinth, Adoptium и
GitHub, чтобы скачать версии игры, моды и Java.

## 7. Изменения политики

Если появятся новые функции с передачей данных, этот документ обновится
до их выпуска, а в описании релиза будет отдельная пометка.
