# История изменений

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версии — [Semantic Versioning](https://semver.org/lang/ru/).

## [1.8.7] — 2026-11-06

### Изменено
- Установщик теперь создаёт внутри выбранной папки подпапку `VleyzLauncher`.
  В ней живут сам лаунчер, версии игры, Java и логи — всё в одном месте,
  рядом ничего не разбрасывается.
- Если указать уже существующую папку `VleyzLauncher` (обновление поверх),
  вложенная папка не создаётся.

### Исправлено
- Удаление данных проверяет маркер `.vleyzlauncher` внутри `minecraft`:
  при ответе «Y» папка с версиями и мирами удаляется вместе с лаунчером,
  при «N» остаётся на месте вместе с настройками.

## [1.8.6] — 2026-11-06

### Исправлено
- Деинсталлятор больше не удаляет папку установки целиком. Удаляются только
  файлы лаунчера, и только если папка помечена маркером `.vleyz-install`.
  Если лаунчер поставили в папку с игрой или другими файлами, они остаются
  на месте — раньше `rmdir /s /q` сносил всё содержимое.
- Удаление данных теперь спрашивает подтверждение: версии игры, миры,
  скачанные JRE и логи удаляются только по ответу «Y».
- Лаунчер помечает свою папку данных (`.vleyzlauncher`) при первом запуске.
  Чужие каталоги, выбранные вручную, не помечаются и никогда не удаляются.

## [1.8.5] — 2026-11-06

### Добавлено
- Импорт готовых сборок: `.mrpack` из Modrinth и zip с папкой `mods`.
  Файлы качаются по SHA1 из индекса, overrides раскладываются по папкам
  сборки. Архивы CurseForge разбираются только на overrides — без ключа API
  их моды не скачать, об этом честно пишется в лог.
- Обновления модов: сверка установленных `.jar` с Modrinth по SHA1, кнопки
  «Обновить» для одного мода и «Обновить всё». Файлы не с Modrinth не трогаются.
- Ресурспаки и шейдеры из Modrinth: поиск, установка в папку сборки,
  включение и отключение переносом в подпапку `_disabled`.
- Бэкапы миров: zip папки `saves`, хранятся 5 последних. Восстановление
  сохраняет текущие миры рядом в `saves-before-…`.
- Скин: превью головы по нику и сохранение картинки PNG.

### Изменено
- На странице модов появилась панель действий: Modrinth, Сборка, Обновления,
  Паки, Бэкапы, Добавить. Список модов сдвинулся ниже.
- В настройках рядом с ником — кнопка «Скин».

## [1.8.1] — 2026-11-06

### Исправлено
- Настройки: блоки «Тема» и «Язык» больше не наезжают друг на друга.
  Переключатели стоят двумя рядами справа, подписи — слева от кнопок.
- Подсказка про Java у кнопки «Сохранить» укорочена, чтобы не уезжать под
  переключатели темы.

## [1.8.0] — 2026-11-05

### Добавлено
- Поиск и установка модов прямо из лаунчера через Modrinth: выбор загрузчика
  и версии игры, загрузка мода вместе с зависимостями, отчёт «Установлено
  файлов: N».
- Инстансы: у каждой сборки своя папка `mods`, `saves` и `config`. Сборки
  больше не перетирают моды и миры друг друга.
- Поле «Аргументы JVM» в настройках — можно добавить `-XX:+UseG1GC` и другие
  ключи, не только ползунок памяти.
- Английский интерфейс: переключатель языка в настройках, все страницы и
  сообщения переведены. Добавлен `README.en.md`.
- Настройки запоминают выбранный язык, при первом запуске остаётся русский.

## [1.7.2] — 2026-11-04

### Исправлено
- Кнопка «Сетевая игра» больше не серая на 1.16+: клиент получает от лаунчера
  локальный ответ `/privileges`, поэтому считает, что мультиплеер разрешён.
  Раньше офлайн-токен получал отказ от `api.minecraftservices.com`.
- Запросы авторизации и сессии по-прежнему идут в Mojang/Ely.by: вход на
  серверы и проверка лицензии на их стороне не меняются.

## [1.7.1] — 2026-11-04

### Исправлено
- Кнопка «Сетевая игра» больше не серая на 1.16+: клиент получает тип
  пользователя `mojang` для офлайн-профиля и Ely.by, `msa` — для Microsoft.
  Правило общее для всех версий, где Minecraft поддерживает `--userType`.
- CLI синхронизирует `servers.dat` при каждом запуске, а не только при
  подключении к серверу из командной строки.

## [1.7.0] — 2026-11-03

### Добавлено
- Обновление в один клик: кнопка «Обновление» скачивает установщик, сверяет
  размер и SHA256, ставит его поверх и перезапускает лаунчер.
- Докачка загрузок: оборванный файл продолжается с места обрыва (HTTP Range),
  прогресс учитывает уже скачанное.
- «Проверить файлы» на главной: докачивает недостающее и проверяет SHA1.
  Для Forge/NeoForge не запускает установщик заново.
- Тесты докачки для серверов с Range и без него.

### Изменено
- Кнопка «Аккаунт» на главной называется «Войти».
- Проверка обновлений показывает прогресс скачивания прямо на кнопке.

## [1.6.0] — 2026-11-03

### Добавлено
- Проверка обновлений по релизам GitHub: кнопка в сайдбаре и ручная проверка
  на странице «О лаунчере».
- Файловые логи с ротацией и единый перехват ошибок: падение больше не выглядит
  немым, путь к логу показывается в окне.
- Версия в свойствах `VleyzLauncher.exe` и `VleyzLauncher-Setup.exe`.
- Portable-архив и SHA256 в релизе, unit-тесты ядра, проверка совпадения версий.
- Лицензия MIT, этот changelog.

### Изменено
- Конфиг переехал из папки программы в `%APPDATA%\VleyzLauncher\config.json`.
  Старый файл переносится автоматически.
- Секреты в конфиге (пароль и токены Ely.by, токены Microsoft) шифруются
  средствами Windows (DPAPI) и не читаются на другом компьютере.
- Запись конфига стала атомарной — обрыв питания не оставит битый json.
- Версия приложения берётся из одного места, User-Agent больше не врёт.

## [1.5] — 2026-11-03
