Крупное обновление. Собирается локально, в релиз не выкладывается до
готовности всего плана.

### Добавлено
- Каталог модов Modrinth (перенесён из 1.9.6): поиск, фильтры, карточки,
  установка с зависимостями.
- Генератор сборок: запрос словами, пресеты, подбор модов под версию игры
  и загрузчик.
- Разбор запроса через GigaChat для тех, у кого есть ключи.
- Плагины-пресеты из JSON в папке данных.
- Диагностика: отчёт о системе и экспорт логов архивом.
- Избранное в каталоге: звезда на карточке и фильтр.
- Экспорт списка модов в txt/json и кнопка папки конфигов.
- Проверка здоровья сборки: дубли модов и моды на vanilla.
- Офлайн-копия каталога: последняя выдача живёт неделю.
- Сборщик: выбор лимита модов и кнопка «Ещё вариант».
- Резервная копия модов перед установкой из сборщика.
- SQLite-кэш ответов Modrinth.
- Переключение сборки прямо в каталоге модов.
- Разбор последнего краш-лога: описание, причина, подозреваемые моды.
- Экспорт сборки в `.mrpack` для Modrinth (незнакомые файлы — в overrides).
- Каталог модпаков Modrinth: поиск, категории, сортировка, версии и
  установка в отдельную сборку в один клик.
- Список версий делится на «Релизы», «Снапшоты» и «Старые»: пагинация
  переехала вниз, счётчик показывает выбранную вкладку.
- Новости Minecraft: официальная лента Mojang в модалке «Что нового»,
  карточки открывают статьи на minecraft.net.
- Установщик собирает всё в одной папке: `VleyzLauncher.exe`, `minecraft`,
  `java` и `logs` появляются сразу; есть быстрые кнопки «Рабочий стол»,
  «Документы», «По умолчанию» и «Открыть папку» после установки.
- Скин и плащ: скин берётся по нику, по прямой ссылке с любого сайта скинов
  или из файла, проверяется как настоящий PNG 64×64 (старый 64×32 тоже
  принимается) и ставится на аккаунт Microsoft в формате classic или slim.
  Плащи аккаунта читаются из профиля Mojang; свои плащи поставить нельзя —
  такого API нет, их рисуют моды, и из модалки есть переход в каталог модов.

### Совместимость
- Лаунчер работает на Windows 7 SP1, Windows 10 и Windows 11: сборка идёт на
  Python 3.8, поэтому не требует Windows 10 и новее.
- На Windows 7 не предлагается Java 17: Adoptium выпускает её только под
  Windows 10+. Вместо падения показывается понятное сообщение, что нужна
  версия игры до 1.17 (на Java 8).
- HTTPS-запросы идут с корневыми сертификатами certifi из комплекта: на
  Windows 7 со старым хранилищем сертификатов Mojang иначе не открывается.
- Запись `servers.dat` идёт несжатым NBT, как у самой игры: список серверов
  больше не теряется при открытии экрана «Сетевая игра».

### Надёжность
- Конфиг пишется атомарно: недописанный файл не заменит рабочий.
- Установка модов идёт через стадию: при обрыве папка mods остаётся
  прежней, старые файлы возвращаются.
- Конфиг проверяется и чинится при загрузке: ник, память, темы, списки
  серверов, профилей и избранного.
- Сеть: экспоненциальная пауза с джиттером, уважение `Retry-After`,
  без бессмысленных повторов на 4xx.
- Исправлено: выбор свежего краш-лога при гонке файлов, лишнее
  сканирование папки модов в проверке здоровья.
- Метаданные модов из jar: дубли по mod id и недостающие зависимости
  теперь видны в проверке здоровья.
- Шина событий ядра (`config.saved`) и раннер фоновых задач с
  дедупликацией и сохранением ошибок.

### Безопасность
- Деинсталлятор больше не может снести лишнее: папку установки он удаляет
  только целиком пустой (`rmdir` без `/s`), трогает лишь свои файлы по
  именам, отказывается работать с корнем диска, профилем, `Program Files`,
  `Windows`, рабочим столом, документами и загрузками, а скачанный JDK
  (`java\bin\java.exe`) считает чужим и оставляет. Путь `TEMP` с хвостовым
  слэшем больше не вызывает бесконечное копирование самого себя.
- Токен аккаунта Minecraft маскируется в логе запуска игры и при записи
  команды запуска.
- Для GigaChat запрещено повторять запросы с отключённой проверкой TLS;
  при ошибке сертификата соединение завершается.
- JRE распаковывается с проверкой путей и ограничениями размера во временную
  папку; небезопасный архив отклоняется без повреждения прежней установки.
- Если DPAPI не может зашифровать секрет, конфиг не сохраняется вместо
  записи секрета открытым текстом.
